# AI SOC Lab — інструкція українською

## Що зроблено

- VMware: `Wazuh-SIEM` (`192.168.238.135`) і `Ubuntu-SOC` (`192.168.238.136`).
- Wazuh Agent з `Ubuntu-SOC` передає події на сервер.
- Через Dashboard підтверджено синтетичну подію невдалого входу SSH з користувачем `soc-test`.
- Wazuh Indexer слухає `127.0.0.1:9200` усередині серверної VM.
- Windows підключається через SSH-тунель, а не через відкритий мережевий порт 9200.
- Створено роль `wazuh_soc_reader` і користувача `soc_reader` для читання індексів `wazuh-alerts-*`.
- Перевірено читання подій і заборону доступу `soc_reader` до адміністративного API (`403 Forbidden`).
- Python на Windows читає сповіщення, передає їх локальній Qwen 3.5 4B у LM Studio та зберігає Markdown-звіти.

## Що запустити наступного разу

1. У VMware увімкнути обидві Ubuntu VM.
2. У LM Studio завантажити Qwen 3.5 4B Instruct і запустити локальний сервер `127.0.0.1:1234`.
3. У першому PowerShell увімкнути SSH-тунель і залишити вікно відкритим:

   ```powershell
   ssh -i "$HOME\.ssh\id_ed25519_wazuh" -N -L 127.0.0.1:9200:127.0.0.1:9200 vitalii@192.168.238.135
   ```

4. У другому PowerShell перейти в папку проєкту і запустити:

   ```powershell
   cd "$HOME\AI-SOC-Lab"
   .\.venv\Scripts\python.exe soc_assistant.py
   ```

5. Ввести пароль `soc_reader` (не `admin`). Не вставляти пароль у чат або код.
6. Перевірити результат у папці `reports`.

## Що робить скрипт

Він бере **до 20 останніх** подій агента `ubuntu-soc` з рівнем Wazuh **5+**, пропускає ID, які вже є в `processed_events.json`, і створює Markdown-звіти. Це **запуск за командою**, а не постійний фоновий моніторинг.

## Що не публікувати в GitHub

`root-ca.pem`, `processed_events.json`, `reports/`, `.venv/`, SSH-ключі, паролі, внутрішні журнали, особисті дані. Перед публікацією перевірити `git status` і `git diff --cached`.

## Якщо виникла проблема

- `Connection refused` для `127.0.0.1:9200`: перевірити, чи SSH-тунель ще відкритий.
- `401 Unauthorized`: неправильний пароль або ім'я користувача.
- `403 Forbidden`: перевірити роль `soc_reader`, шаблон індексів і потрібні дозволи.
- `SSLCertVerificationError`: перевірити CA і відповідність адреси сертифікату; не вимикати перевірку TLS у фінальній версії.
- LM Studio `Connection refused`: перевірити модель та локальний сервер на порту 1234.
- Qwen повернув порожню відповідь: перевірити ліміт токенів, завантаження моделі й доступну RAM/VRAM.
